# حارس يونس v13

هذه النسخة تحتوي على المشروع الكامل + GitHub Actions جاهز لبناء APK.

## مهم جدًا عند الرفع إلى GitHub
إذا كان GitHub على الهاتف لا يسمح برفع مجلد كامل، لا ترفع الملفات واحدًا واحدًا من داخل `app`.

استخدم أحد الخيارين:
1. افتح GitHub من متصفح بوضع سطح المكتب وارفع محتويات المشروع دفعة واحدة إذا كان مدير الملفات يسمح بتحديد المجلد.
2. أو استخدم Git/Termux لرفع المجلد كاملًا.

بعد وصول الملفات إلى المستودع، افتح Actions ثم Build Haras Younis APK ثم Run workflow.

الناتج: Artifacts > Haras-Younis-APK > app-debug.apk
